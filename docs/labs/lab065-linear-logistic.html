Part 1

Linear regression — predicting continuous values

Linear regression is a statistical and machine learning method used to model the relationship between a dependent variable and one or more independent variables. Its goal is to find a line (or hyperplane) that best fits the data.

\[ y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 x_3 + \dots + \beta_n x_n + \varepsilon \]
  • \(y\) — dependent variable (the output value we predict)
  • \(x_1, x_2, \dots, x_n\) — independent variables (input values for the features)
  • \(\beta_0, \beta_1, \dots, \beta_n\) — the coefficients we learn (\(w_0, w_1, \dots, w_n\) on the slides)
  • residual: \(y_{actual} - y_{pred}\)

1. Simple linear regression

In simple linear regression, we model the relationship between an input variable \(x\) and an output variable \(y\) with the equation \(y = \beta_0 + \beta_1 x + \varepsilon\), where:

  • \(\beta_0\) is the intercept
  • \(\beta_1\) is the slope
  • \(\varepsilon\) is the error term

The predicted value is written as \(\hat{y} = \beta_0 + \beta_1 x\).

Goal functionApproximation with the model
\(y = \beta_0 + \beta_1 x + \varepsilon\)\(\hat{y} = \beta_0 + \beta_1 x\)

2. Interpretation

  • The intercept \(\beta_0\) is the predicted value of \(y\) when \(x = 0\).
  • The slope \(\beta_1\) tells us how much \(y\) changes when \(x\) increases by 1 unit.

For example, if \(\hat{y} = 2 + 3x\), then when \(x = 0\), \(\hat{y} = 2\), and for every increase of 1 in \(x\), \(\hat{y}\) increases by 3.

Meaning of the error term

\(\varepsilon\) (the error term) is the difference between the actual value and the value predicted by the linear model: \(\varepsilon = y - \hat{y}\). It exists because real-world data is never perfectly linear. Even if \(x\) strongly influences \(y\), there are always other factors affecting the outcome. The error term captures:

  1. Missing variables: variables that affect \(y\) but are not included in the model. Example: predicting salary from education, \(salary = \beta_0 + \beta_1 \cdot education + \varepsilon\). But salary also depends on experience, skills, location, industry — these influences appear inside \(\varepsilon\).
  2. Random noise: natural randomness in measurements or behaviour. Example: two people with the same study hours may get different exam scores due to stress, luck, or question difficulty.
  3. Model imperfection: the true relationship might not be perfectly linear. Example: the real relationship might be \(y = 2 + 3x + 0.5x^2\), but if we fit a linear model, the difference is absorbed into \(\varepsilon\).

Intuition

Actual value = predictable part + unpredictable part: \(y = (\beta_0 + \beta_1 x) + \varepsilon\). The model tries to estimate \(\beta_0\) and \(\beta_1\) so that the errors \(\varepsilon\) are as small as possible.

In practice, we do not directly observe \(\varepsilon\) — we estimate it using the residual \(= y - \hat{y}\). Residuals are our observed approximations of the true error terms. Without the error term, the model would assume perfect predictions, which almost never happens in real data. The error term makes the model statistically realistic and allows us to analyse uncertainty.

3. Cost function

To find the best-fitting line, linear regression minimizes the sum of squared errors. For \(n\) data points, the cost function is:

\[ J(\beta_0, \beta_1) = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2 \]

Since \(\hat{y}_i = \beta_0 + \beta_1 x_i\), this becomes:

\[ J(\beta_0, \beta_1) = \frac{1}{n} \sum_{i=1}^{n} (\beta_0 + \beta_1 x_i - y_i)^2 \]

This is also called the mean squared error (MSE), up to a constant factor depending on convention.

4. Finding the best line

The optimal values of \(\beta_0\) and \(\beta_1\) are chosen so that the cost function is as small as possible. To find them, we minimize the cost function using partial derivatives — commonly with gradient descent.

Partial derivative with respect to \(\beta_0\)

Apply the chain rule to each term \(i = 1 \dots n\):

\[ \frac{\partial}{\partial \beta_0}(\beta_0 + \beta_1 x_i - y_i)^2 = 2(\beta_0 + \beta_1 x_i - y_i) \cdot \frac{\partial}{\partial \beta_0}(\beta_0 + \beta_1 x_i - y_i) \]

Differentiate the inner expression:

\[ \frac{\partial}{\partial \beta_0}(\beta_0 + \beta_1 x_i - y_i) = 1 \]

Apply this to the entire sum and factor out constants:

\[ \frac{\partial J}{\partial \beta_0} = \frac{1}{n}\sum_{i=1}^{n}2(\beta_0 + \beta_1 x_i - y_i) = \frac{2}{n}\sum_{i=1}^{n}(\beta_0 + \beta_1 x_i - y_i) \]

Partial derivative with respect to \(\beta_1\)

\[ \frac{\partial}{\partial \beta_1}(\beta_0 + \beta_1 x_i - y_i)^2 = 2(\beta_0 + \beta_1 x_i - y_i) \cdot \frac{\partial}{\partial \beta_1}(\beta_0 + \beta_1 x_i - y_i) \]

Differentiate the inner expression:

\[ \frac{\partial}{\partial \beta_1}(\beta_0 + \beta_1 x_i - y_i) = x_i \]

Combine the results and apply to the full cost function:

\[ \frac{\partial J}{\partial \beta_1} = \frac{1}{n}\sum_{i=1}^{n}2(\beta_0 + \beta_1 x_i - y_i)\,x_i = \frac{2}{n}\sum_{i=1}^{n}(\beta_0 + \beta_1 x_i - y_i)\,x_i \]

Gradient descent update rules

After computing the gradients, we update the parameters in the opposite direction of the gradient, where \(\alpha\) is the learning rate:

\[ \beta_0 := \beta_0 - \alpha \frac{\partial J}{\partial \beta_0} \qquad \beta_1 := \beta_1 - \alpha \frac{\partial J}{\partial \beta_1} \]

Substituting the derivatives:

\[ \beta_0 := \beta_0 - \alpha \frac{2}{n}\sum_{i=1}^{n}(\beta_0 + \beta_1 x_i - y_i) \qquad \beta_1 := \beta_1 - \alpha \frac{2}{n}\sum_{i=1}^{n}(\beta_0 + \beta_1 x_i - y_i)\,x_i \]

Intuition

The partial derivatives measure how much the cost function changes when we slightly change a parameter.

  • If the derivative is positive, increasing the parameter increases the cost.
  • If the derivative is negative, increasing the parameter decreases the cost.

Gradient descent repeatedly updates the parameters to move downhill on the cost surface, gradually finding the best-fitting line.

Closed-form solution

For simple linear regression, the closed-form solution is obtained directly by solving \(\frac{\partial J}{\partial \beta_0} = 0\) and \(\frac{\partial J}{\partial \beta_1} = 0\):

\[ \beta_1 = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n}(x_i - \bar{x})^2} \qquad \beta_0 = \bar{y} - \beta_1 \bar{x} \]

where \(\bar{x}\) is the mean of the input values and \(\bar{y}\) is the mean of the output values.

Comparing closed form with gradient descent

MethodIdeaParametersRule
Gradient descentMove gradually downhillUpdated repeatedly using \(\alpha\)\(\beta \leftarrow \beta - \alpha \nabla J(\beta)\)

The closed form works well for small linear regression problems, but it becomes expensive when there are many features because it requires matrix inversion. Gradient descent:

  • works for large datasets
  • works for neural networks
  • works for models without closed-form solutions

That is why machine learning libraries usually rely on gradient-based optimization.

5. Multiple linear regression

When there are multiple input variables, the model becomes:

\[ y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_p x_p + \varepsilon \qquad \hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_p x_p \]

In matrix form, this is often written as \(\hat{y} = X\beta\), where \(X\) is the design matrix and \(\beta\) is the vector of coefficients. The normal equation gives the solution:

\[ \beta = (X^T X)^{-1} X^T y \]

6. Assumptions of linear regression

Linear regression works best when several assumptions are approximately true:

  1. Linearity: an approximately linear relationship between the input data and the output.
  2. Independence: observations should be independent; the error for one data point should not depend on another.
  3. Homoscedasticity: the variance of the errors must be constant for all predictor values.
  4. Normality of errors: errors are approximately normally distributed.
  5. No strong multicollinearity: predictors are not highly correlated with each other.

7. Evaluating the model

A common metric is the coefficient of determination \(R^2\):

\[ R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2} \]
  • \(R^2 = 1\) means a perfect fit.
  • \(R^2 = 0\) means the model does no better than predicting the mean. (Try a flat line through the mean in the residual playground above.)

Another common metric is the root mean squared error:

\[ RMSE = \sqrt{\frac{1}{n} \sum_{i=1}^{n}(y_i - \hat{y}_i)^2} \]

8. Example

Suppose we want to predict exam score \(y\) from study hours \(x\). A fitted model might be \(\hat{y} = 40 + 5x\). This means:

  • a student who studies 0 hours is predicted to score 40;
  • each additional study hour increases the predicted score by 5 points.

Part 2

Logistic regression — classification

Using regression for classification

Although regression is typically used to predict continuous values, any regression technique can also be adapted for classification. Instead of predicting a numeric quantity, we train a separate regression model for each class.

Training phase — for each class, perform a regression model specific to that class, with the training outputs:

  • 1 for training instances that belong to the class;
  • 0 for instances that do not belong to the class.

Each model learns how strongly an instance belongs to its corresponding class.

Prediction phase — to classify a new instance:

  1. Evaluate all regression models.
  2. Each model produces a membership value (a score).
  3. The predicted class is the one whose model produces the largest output value: \(\hat{y} = \arg\max_k f_k(x)\), where \(f_k(x)\) is the regression output for class \(k\).

When linear regression is used in this framework, the method is called multi-response linear regression: multiple outputs are predicted simultaneously — one for each class.

Problem with regression-based classification

A key limitation is that the membership values are not guaranteed to lie in the range \([0, 1]\). As a result, they cannot be interpreted as valid probabilities — outputs may even be negative or greater than 1. In practice, the outputs are often adjusted using simple heuristics:

  1. clip values into the range \([0, 1]\);
  2. normalize them so that the values sum to 1.

This produces values that resemble probability estimates, although they are not theoretically well-founded probabilities.

Moving to logistic regression

Linear regression can be adapted for classification, but its predictions are not restricted to the range \([0, 1]\). To address this issue, we use logistic regression, a model specifically designed for classification.

Key idea: logistic regression builds a linear model for a transformed target variable instead of modeling the probability directly. With two classes (class 0 and class 1), the model predicts the probability that an instance belongs to class 1, \(P(1 \mid a_1, a_2, \dots, a_k)\), where \(a_1, \dots, a_k\) are the input features.

Odds, log-odds and the logit transformation

  • The odds of class 1 are the ratio between the probability of class 1 and the probability of class 0: \(\dfrac{P(1 \mid a_1,\dots,a_k)}{1 - P(1 \mid a_1,\dots,a_k)}\).
  • Taking the logarithm of the odds gives the log-odds, or logit: \(\text{logit}(p) = \log\left(\dfrac{p}{1-p}\right)\).

Why use the logit transformation? Probabilities are restricted to \(p \in [0, 1]\), but a linear model can produce values anywhere in \((-\infty, +\infty)\). The logit solves this mismatch: \(\text{logit}: [0,1] \rightarrow (-\infty, +\infty)\). After the transformation, the target is no longer restricted and can be modeled with a linear function.

📐 Linear model in logistic regression

Logistic regression assumes that the log-odds are a linear function of the features:

\[ \log\left(\frac{p}{1-p}\right) = w_0 + w_1 x_1 + \dots + w_n x_n \]

The model is still linear in the parameters, but it operates on the transformed probability.

Recovering the probability: the sigmoid

To convert the linear output back to a probability, we apply the inverse logit — the logistic (sigmoid) function. With the linear score \(z = w_0 + w_1 x_1 + \dots + w_n x_n\):

\[ P(z) = \frac{1}{1 + e^{-z}} \qquad 0 \le P \le 1 \]

The model outputs a probability \(p\); to convert it to a class prediction we threshold it:

\[ \hat{y} = \begin{cases} 1 & \text{if } p \ge 0.5 \\ 0 & \text{if } p < 0.5 \end{cases} \]

The model

Given input features \(x\), logistic regression computes a linear score \(z = w^T x + b\), converted into a probability using the sigmoid function:

\[ \hat{p} = \sigma(z) = \frac{1}{1 + e^{-z}} \qquad \hat{p} = P(y = 1 \mid x) \qquad P(y = 0 \mid x) = 1 - \hat{p} \]

Probability of one training example

The probability the model assigns to the observed label is \(\hat{p}\) if the true label is 1, and \(1 - \hat{p}\) if the true label is 0. This simply means the model should assign high probability to the correct label.

Probability of the whole dataset — the likelihood

With \(n\) training examples that are independent given the model parameters, the probability of observing the entire dataset is the product of the probabilities of each example — the likelihood:

\[ L(w) = \prod_{i=1}^{n} P(y_i \mid x_i) = \left(\prod_{i : y_i = 1} \hat{p}_i \right)\left(\prod_{i : y_i = 0} (1 - \hat{p}_i)\right) \]

Log-likelihood

Using the compact form \(P(y_i \mid x_i) = \hat{p}_i^{\,y_i} (1-\hat{p}_i)^{1-y_i}\) with \(y_i \in \{0, 1\}\), the likelihood is \(L(w) = \prod_{i=1}^{n} \hat{p}_i^{\,y_i}(1-\hat{p}_i)^{1-y_i}\), and taking the logarithm converts the product into a sum:

\[ \log L(w) = \sum_{i=1}^{n} \left[ y_i \log(\hat{p}_i) + (1-y_i)\log(1-\hat{p}_i) \right] \]

Loss function: binary cross-entropy

Machine learning models are trained by minimizing a loss function, so we minimize the negative log-likelihood:

\[ J(w) = -\frac{1}{n} \sum_{i=1}^{n} \left[ y_i \log(\hat{p}_i) + (1 - y_i)\log(1 - \hat{p}_i) \right] \]

This loss is called binary cross-entropy. Intuition:

  • If the true label is 1: loss \(= -\log(\hat{p})\) — a prediction close to 1 gives a small loss, close to 0 a very large loss.
  • If the true label is 0: loss \(= -\log(1 - \hat{p})\) — a prediction close to 0 gives a small loss, close to 1 a very large loss.

Therefore the loss strongly penalizes confident but incorrect predictions.

Gradient descent

Gradient descent updates parameters in the direction that reduces the loss. General update rule, where \(\theta\) is a parameter and \(\eta\) is the learning rate:

\[ \theta = \theta - \eta \frac{\partial J}{\partial \theta} \]

For logistic regression, the derivative simplifies nicely. For one example, \(\dfrac{\partial L}{\partial z} = \hat{y} - y\) — the gradient depends on the prediction error. Using the chain rule:

\[ \frac{\partial L}{\partial w} = (\hat{y} - y)\,x \qquad \frac{\partial J}{\partial w} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)\,x_i \qquad \frac{\partial J}{\partial b} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i) \]

Parameter update rules:

\[ w := w - \eta \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)\,x_i \qquad b := b - \eta \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i) \]

Intuition: the term \((\hat{y} - y)\) is the prediction error. If the model predicts too high → weights decrease; if it predicts too low → weights increase. Each feature \(x\) scales how much the weight changes.

What happens with perfectly separable data?

With \(p(y_i = 1 \mid x_i) = \sigma(w^T x_i + b)\), logistic regression maximizes the log-likelihood

\[ \ell(w, b) = \sum_{i=1}^{n} \left[ y_i \log(p_i) + (1 - y_i)\log(1 - p_i) \right] \]

If the data is perfectly separable, logistic regression can always increase the likelihood further by making the weights larger, because larger weights push the probabilities closer to \(p = 1\) for positives and \(p = 0\) for negatives. It keeps thinking: "If I increase the weights, I can make my predictions more confident." Switch the playground above to Perfectly separable and watch \(\lVert w \rVert\) keep growing.

Logistic regression with multiple classes

One-vs-Rest (OvR)

If there are \(K\) classes, we train \(K\) separate logistic regression models. Each model predicts the probability \(P(y = k \mid x)\): is input example \(x\) from class \(k\) or not?

  1. Compute the probability from each model.
  2. Choose the class with the highest probability — the class where \(x\) belongs: \(\hat{y} = \arg\max_k P(y = k \mid x)\).

Multinomial logistic regression (softmax)

Instead of training separate models, we use the softmax function to compute probabilities for all classes at once. This extension is called multiclass logistic regression or softmax regression: the model predicts a probability distribution over all classes.

Problem setup: input features \(x \in \mathbb{R}^d\), \(K\) classes, labels \(y \in \{1, 2, \dots, K\}\). For each class \(k\), the model learns a weight vector \(w_k\) and a bias \(b_k\).

Linear scores (logits): for every class we compute \(z_k = w_k^T x + b_k\) (on the slides: \(z_k = w_{k0} + w_{k1} x_1 + \dots + w_{kn} x_n\)). Collecting all scores gives the vector \(z = [z_1, z_2, \dots, z_K]\) — the logits.

📐 Softmax
\[ P(y = k \mid x) = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}} \qquad \sum_{k=1}^{K} P(y = k \mid x) = 1 \]

This ensures the probabilities are positive and sum to 1. The prediction is the class with the largest probability: \(\hat{y} = \arg\max_k P(y = k \mid x)\).

Likelihood and loss: assuming independent examples, \(L(W) = \prod_{i=1}^{n} P(y_i \mid x_i)\), and the log-likelihood is

\[ \log L(W) = \sum_{i=1}^{n} \log P(y_i \mid x_i) = \sum_{i=1}^{n} \left( z_{i,y_i} - \log \sum_{k=1}^{K} e^{z_{i,k}} \right) \]

We minimize the negative log-likelihood — the multiclass cross-entropy:

\[ J(W) = -\frac{1}{n} \sum_{i=1}^{n} \log P(y_i \mid x_i) = -\frac{1}{n} \sum_{i=1}^{n} \log \left( \frac{e^{z_{i,y_i}}}{\sum_{k=1}^{K} e^{z_{i,k}}} \right) \]

Example: classifying fruit

We classify fruit into \(K = 3\) classes — apple, banana, orange — using the features weight and sweetness. For one fruit \(x = [2, 1]\), the model computes the logits \(z = [1.2, 0.3, 2.1]\). The calculator starts from these values; drag the logits or change the true label.

What happens if the model is wrong? If the model predicted \(P(apple) = 0.7,\ P(banana) = 0.2,\ P(orange) = 0.1\) but the true class is orange, the loss becomes \(-\log(0.1) \approx 2.30\). This large loss strongly penalizes confident incorrect predictions.

Assumptions of logistic regression

  1. The training examples should be independent of each other.
  2. Linear relationship with the log-odds: \(\log\left(\frac{p}{1-p}\right) = w_0 + w_1 x_1 + \dots + w_n x_n\).
  3. Predictor variables should not be highly correlated with each other.
  4. Large sample size.
  5. No extreme outliers in predictors — extreme values in the features can strongly affect the estimated coefficients.
