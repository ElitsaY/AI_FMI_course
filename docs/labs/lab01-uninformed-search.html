Aside

Local search, in one breath

Local search doesn't build a tree at all — it moves from candidate solution to candidate solution, only caring about where it ends up, not the path it took. Useful when the path is irrelevant and the space is too big to search exhaustively; the strategies below are the opposite approach, where the path is the answer.
